## Prompt Explanation

The user wanted a complete, production-grade Go backend for an existing React NGO platform. Key challenges:

1. Understand the existing frontend (16 screens, 4-file pattern, centralised API layer)
2. Design 9-table schema with TIMESTAMPTZ, unique constraints, and proper indexes
3. Wire Cloudinary, Twilio (SMS), Resend (email) as external services
4. Implement OTP auth with rate-limiting, dev mode bypass, and auto-registration
5. Handle approval flows transactionally (donation certificate, ID card number with collision retry)
6. Protect against DoS (body cap), duplicate submissions (idempotency), table bloat (cleanup goroutine)
7. Ship a clean CI/CD pipeline with path-filter to only rebuild on api/** changes
