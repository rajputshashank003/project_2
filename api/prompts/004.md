# Prompt 004 — Org Settings Key-Value Store & User Profile Endpoints

**Date:** 2026-08-15  
**Scope:** Backend (`api/`)

---

## User Request

1. Refactor `ngo_config` table from a single-row wide table into a flexible `org_settings` key-value table.
2. Store auxiliary metadata (like Cloudinary IDs for logo and digital signature) in a dedicated `meta` JSON row.
3. Fix the `500 Internal Server Error` on `GET /api/v1/ngo/config`.
4. Add `user_id` foreign key to `donations` and support per-user querying for user profiles (`/api/v1/my/donations` and `/api/v1/my/id-cards`).

---

## What Was Done

### 1. Migrations
- `000011_create_org_settings.up.sql`: Created `org_settings (id, key, value, created_at, updated_at)` with unique index on `key`. Migrated existing data from `ngo_config` and dropped `ngo_config`.
- `000011_create_org_settings.down.sql`: Recreated `ngo_config` from `org_settings` on rollback.
- `000012_add_user_id_to_donations.up.sql`: Added `user_id UUID REFERENCES users(id) ON DELETE SET NULL` with index `idx_donations_user_id`.
- `000012_add_user_id_to_donations.down.sql`: Dropped index and column.

### 2. Models & Repository
- `models/org_setting.go`: Defined `OrgSetting`, `NgoConfigResponse`, typed key constants (`OrgKeyName`, `OrgKeyUPIID`, etc.), and `OrgMetaJSON`. Added `TableName() string` returning `"org_settings"`.
- `models/ngo_config.go`: Replaced with backward-compatible alias `type NgoConfig = NgoConfigResponse`.
- `models/donation.go`: Added `UserID *uuid.UUID` field.
- `repository/org_settings_repository.go`: Implemented `GetAll()`, `Set()`, `BulkSet()`, `GetMeta()`, and `SetMeta()`.
- `repository/donation_repository.go`: Added `ListByUserID(userID, offset, limit)`.
- `repository/id_card_repository.go`: Added `ListByUserID(userID, offset, limit)`.

### 3. Services & Handlers
- `service/ngo_service.go`: Converted to work with `OrgSettingsRepository`. Implemented `kvToResponse()` and `SetMeta()` for Cloudinary tracking.
- `service/donation_service.go`: Updated `Create(ctx, userID, req)` to attach `user_id` and added `ListByUser(userID, page, limit)`.
- `service/id_card_service.go`: Added `ListByUser(userID, page, limit)`.
- `handler/ngo_handler.go`: Added zerolog error logging to `GetConfig`.
- `handler/donation_handler.go`: Extracted `userID` from auth context in `Create()` and added `ListMy()`.
- `handler/id_card_handler.go`: Added `ListMy()`.
- `routes/routes.go`: Registered `/my/donations` and `/my/id-cards` under auth middleware.
- `cmd/server/main.go`: Wired `OrgSettingsRepository` in DI.
