# Prompt 006 — Migration from Base64 File Uploads to Multipart/FormData

**Date:** 2026-08-16  
**Scope:** Backend (`api/`)

---

## User Request

> "why we are sending base64 in backend we should send file and formdata fix this in all place in this repo"

---

## What Was Done

### 1. Cloudinary Service Stream Uploads
- `internal/service/cloudinary_service.go`:
  - Added `UploadFile(ctx context.Context, file io.Reader) (CloudinaryResult, error)` to stream `multipart.File` / `io.Reader` directly to Cloudinary without base64 decoding.
  - Kept legacy `Upload` as a deprecated wrapper around `UploadFile` using `bytes.NewReader`.

### 2. Migration of All Backend Endpoints to Multipart/FormData
1. **Donations (`POST /api/v1/donations`)**:
   - `internal/dto/donation_dto.go`: Added `form` tags to `CreateDonationRequest`, removed `PaymentScreenshotB64`.
   - `internal/service/donation_service.go`: `Create(ctx, userID, req, file io.Reader)` streams screenshot file directly to Cloudinary.
   - `internal/handler/donation_handler.go`: Reads `paymentProof` / `paymentScreenshot` using `c.FormFile()` and binds form fields via `c.ShouldBind(&req)`.
2. **ID Cards (`POST /api/v1/id-cards`)**:
   - `internal/dto/id_card_dto.go`: Added `form` tags to `CreateIDCardRequest`, removed base64 fields.
   - `internal/service/id_card_service.go`: `Create(ctx, req, userID, passportFile io.Reader, paymentFile io.Reader)` streams both files directly to Cloudinary.
   - `internal/handler/id_card_handler.go`: Reads `passportPhoto` and `paymentScreenshot`/`paymentProof` using `c.FormFile()`.
3. **Gallery (`POST /api/v1/gallery`)**:
   - `internal/dto/gallery_dto.go`: Added `form:"caption"` tag to `UploadGalleryRequest`.
   - `internal/service/gallery_service.go`: `Upload(ctx, caption, file io.Reader, uploadedBy)` streams image directly.
   - `internal/handler/gallery_handler.go`: Reads `image` via `c.FormFile("image")` and `caption` via `c.PostForm("caption")`.
4. **Notices (`POST /api/v1/notices`)**:
   - `internal/dto/notice_dto.go`: Added `form` tags to `CreateNoticeRequest`.
   - `internal/service/notice_service.go`: `Create(ctx, req, file io.Reader, createdBy)` handles optional image streaming.
   - `internal/handler/notice_handler.go`: Reads optional `image` file via `c.FormFile("image")`.
5. **Team Members (`PATCH /api/v1/team/:slot`)**:
   - `internal/dto/team_dto.go`: Added `form` tags to `UpdateTeamMemberRequest`.
   - `internal/service/team_service.go`: `UpdateSlot(ctx, slot, req, file io.Reader)` replaces photo via streaming and cleans up old Cloudinary asset.
   - `internal/handler/team_handler.go`: Reads optional `photo` via `c.FormFile("photo")`.
6. **Events (`POST /api/v1/events` & `PATCH /api/v1/events/:id`)**:
   - `internal/dto/event_dto.go`: Added `EventImageUpload` struct (`File io.Reader`, `ExistingURL string`, `Caption string`).
   - `internal/service/event_service.go`: Streams new image files, preserves existing image URLs, and removes orphaned Cloudinary assets.
   - `internal/handler/event_handler.go`: Parses `c.MultipartForm()` for multi-image uploads and captions.
7. **NGO / Org Config (`PATCH /api/v1/ngo/config`)**:
   - `internal/dto/ngo_dto.go`: Added `form` tags, `RemoveLogo *bool`, and `RemoveSignature *bool`.
   - `internal/service/ngo_service.go`: Streams `logo` and `signature` files directly; supports deleting via remove flags.
   - `internal/handler/ngo_handler.go`: Extracts `logo` and `signature` via `c.FormFile()` with JSON/form binding fallback.
