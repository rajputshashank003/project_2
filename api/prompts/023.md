# Prompt 023 — Dynamic CORS Origins via `FE_URLS`

**Date:** 2026-08-18  
**Scope:** Backend (`api/`)

---

## User Requests

1. Add CORS policy and pick CORS frontend URLs from environment variable `FE_URLS=xyz.com, abc.com, 2df.app` supporting multiple URLs separated by space, commas, etc.

---

## What Was Done

1. **`internal/config/config.go`**:
   - Added `FEUrls []string` to `Config` struct.
   - Added `parseOrigins(raw string) []string` helper that splits by commas, semicolons, spaces, tabs, or newlines.
   - Normalizes plain domains (e.g. `xyz.com` -> `https://xyz.com` and `http://xyz.com`) and removes trailing slashes and quotes.
   - Parsed `FE_URLS` into `cfg.FEUrls` during `config.Load()`.

2. **`internal/routes/routes.go`**:
   - Updated `routes.Setup(...)` to receive `feURLs []string`.
   - Configured `cors.New(...)`:
     - If `FE_URLS` is empty or `*`, falls back to `AllowAllOrigins: true`.
     - When URLs are provided, sets `AllowOrigins`, `AllowOriginFunc`, `AllowCredentials: true`, full standard HTTP methods (`GET, POST, PATCH, PUT, DELETE, OPTIONS, HEAD`), and standard request/response headers.

3. **`cmd/server/main.go`**:
   - Passed `cfg.FEUrls` to `routes.Setup(...)`.

4. **`.env.example`**:
   - Documented `FE_URLS`.
