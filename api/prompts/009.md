# Prompt 009 — Manager Phone Setting & Automated Request Alerts

**Date:** 2026-08-16  
**Scope:** Backend (`api/`)

---

## User Request

> "create another org setting manager whihc store phone number and if someone request for donation or id then we should send a notification to that manager that someone xyz requested for x ₹ donation or id card, and link to website"  
> "emojis are not requied"

---

## What Was Done

### 1. Model & DTO Updates
- `internal/models/org_setting.go`:
  - Added constant `OrgKeyManagerPhone = "manager_phone"`.
  - Added `ManagerPhone string json:"managerPhone,omitempty"` to `NgoConfigResponse`.
- `internal/dto/ngo_dto.go`:
  - Added `ManagerPhone *string json:"managerPhone" form:"managerPhone"` to `UpdateNgoConfigRequest`.

### 2. Repository & Service Wiring
- `internal/repository/org_settings_repository.go`:
  - Implemented `GetValue(key string) (string, error)` for scalar setting retrieval.
- `internal/service/ngo_service.go`:
  - Handled `req.ManagerPhone` in `Update()` and mapped `ManagerPhone` in `kvToResponse()`.
- `internal/service/donation_service.go`:
  - Injected `orgRepo *repository.OrgSettingsRepository`.
  - On `Create()`, launched asynchronous goroutine `notifyManagerNewDonation(donation)`:
    - Queries `manager_phone` from `org_settings`.
    - If set, sends plain-text WhatsApp alert via `messenger.Send(managerPhone, msg)`.
- `internal/service/id_card_service.go`:
  - Injected `orgRepo *repository.OrgSettingsRepository`.
  - On `Create()`, launched asynchronous goroutine `notifyManagerNewIDCard(card)`:
    - Queries `manager_phone` from `org_settings`.
    - If set, sends plain-text WhatsApp alert via `messenger.Send(managerPhone, msg)`.
- `cmd/server/main.go`:
  - Passed `ngoRepo` into `service.NewDonationService` and `service.NewIDCardService`.
