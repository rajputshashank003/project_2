# Prompt 003 — WhatsApp + Multi-Messenger Service

**Date:** 2026-08-15  
**Author:** AI Agent  
**Scope:** Backend only (`api/`) — zero frontend changes

---

## Context

OTP delivery via Twilio SMS was failing in India due to TRAI DLT regulations (custom message
bodies rejected on trial accounts). WhatsApp was identified as a better alternative since:
- Twilio WhatsApp sandbox allows free-form Body text (no DLT approval)
- `whatsmeow` (unofficial WhatsApp Web library) allows 100% free messaging using a linked device

A `MESSAGING_TYPE` env switch was introduced so any channel can be selected without code changes.

## MESSAGING_TYPE Switch

```env
MESSAGING_TYPE=sms              # → Twilio SMS (DLT required for India prod)
MESSAGING_TYPE=whatsapp_twilio  # → Twilio WhatsApp sandbox / production
MESSAGING_TYPE=whatsapp_local   # → standalone whatsapp_service (whatsmeow, 100% free)
```

All domain services (OTP, Donation, ID Card) use the switch automatically via `MultiMessenger`.

## Notes for Future Agent
