# Prompt 005 — Notification Deep Links, Idempotency Guards, Team Management & User Self-Profile

**Date:** 2026-08-15  
**Scope:** Backend (`api/`)

---

## User Request

1. Remove Twilio SMS fallbacks when `whatsapp_local` is configured.
2. Fix duplicate notification emails on approval.
3. Fix crash/inconsistencies on Admin Team slot clear, add, and remove.
4. Support Mission & Vision in `org_settings` key-value store.
5. Fix event update base64 decoding error when existing Cloudinary image URLs are supplied.
6. Add `APP_BASE_URL` env var and embed deep links to certificates/ID cards in WhatsApp and Email notifications.
7. Add `PATCH /api/v1/my/profile` endpoint for user self-service onboarding (name + email).

---

## What Was Done

### 1. Configuration & Domain Models
- `internal/config/config.go`:
  - Added `AppBaseURL` (`APP_BASE_URL`, default `"https://ngo.costop.in"`).
  - Maintained `MessagingType` logging on startup.
- `internal/models/org_setting.go`:
  - Added `OrgKeyMission = "mission"` and `OrgKeyVision = "vision"`.
  - Added `Mission` and `Vision` fields to `NgoConfigResponse`.
- `internal/dto/ngo_dto.go`:
  - Added `Mission *string` and `Vision *string` to `UpdateNgoConfigRequest`.
- `internal/dto/user_dto.go`:
  - Added `UpdateMyProfileRequest` struct (allows self-update of only `name` and `email`).

### 2. Services
- `internal/service/ngo_service.go`:
  - Mapped `mission` and `vision` in `Update()` and `kvToResponse()`.
- `internal/service/id_card_service.go`:
  - Added `appBaseURL` to `IDCardService`.
  - Added status idempotency guard: if `card.Status == req.Status`, return early to prevent duplicate notifications on retry/double-click.
  - Formatted WhatsApp messages and HTML emails with direct deep links (`{AppBaseURL}/id-card/{cardID}`).
- `internal/service/donation_service.go`:
  - Added `appBaseURL` to `DonationService`.
  - Added status idempotency guard: if `donation.Status == req.Status`, return early.
  - Formatted WhatsApp messages and HTML emails with direct deep links (`{AppBaseURL}/certificate/{donationID}`).
- `internal/service/team_service.go`:
  - `ClearSlot`: Now returns `*models.TeamMember` (reloaded after clear) instead of just error.
  - `AddSlot`: Now returns `([]models.TeamMember, error)` (full updated list).
  - `RemoveSlot`: Now returns `([]models.TeamMember, error)` (full updated list after reindexing).
- `internal/service/event_service.go`:
  - Differentiated between new base64 image strings and existing image URLs (starting with `http`). Skips Cloudinary upload for existing images during event update.
- `internal/service/user_service.go`:
  - Added `UpdateMyProfile(id, req)` method.

### 3. Handlers & Routes
- `internal/handler/team_handler.go`:
  - Updated `ClearSlot`, `AddSlot`, and `RemoveSlot` to return updated data payloads.
- `internal/handler/user_handler.go`:
  - Added `UpdateMyProfile` handler for `PATCH /api/v1/my/profile`.
- `internal/routes/routes.go`:
  - Registered `PATCH /api/v1/my/profile` under authenticated `/my` route group.
- `cmd/server/main.go`:
  - Injected `cfg.AppBaseURL` into `DonationService` and `IDCardService`.
  - Added startup logging for `messagingType` and `appBaseURL`.
