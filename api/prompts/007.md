# Prompt 007 — Migration of org_settings Meta to Table Column

**Date:** 2026-08-16  
**Scope:** Backend (`api/`)

---

## User Request

> "i said meta is a column in this table so anyone want to store extra data they can in json format fix this"

---

## What Was Done

### 1. Database Migration (`000013_add_meta_column_to_org_settings`)
- `000013_add_meta_column_to_org_settings.up.sql`:
  - Added `meta JSONB NOT NULL DEFAULT '{}'::jsonb` column to `org_settings`.
  - Migrated legacy Cloudinary IDs from the row `WHERE key = 'meta'`:
    - Updated `key = 'logo_url'` with `meta = jsonb_build_object('cloudinary_public_id', logo_cid)`.
    - Updated `key = 'signature_url'` with `meta = jsonb_build_object('cloudinary_public_id', sig_cid)`.
  - Deleted the legacy standalone row `DELETE FROM org_settings WHERE key = 'meta'`.
- `000013_add_meta_column_to_org_settings.down.sql`:
  - Rollback recreates `meta` row from `logo_url` and `signature_url` columns and drops `meta` column.

### 2. Models & Struct Updates
- `internal/models/org_setting.go`:
  - Added `Meta json.RawMessage` with GORM tag `gorm:"column:meta;type:jsonb;default:'{}'"` to `OrgSetting`.
  - Removed constant `OrgKeyMeta = "meta"`.
  - Added `CloudinaryAssetMeta` struct (`CloudinaryPublicID string`).

### 3. Repository Updates
- `internal/repository/org_settings_repository.go`:
  - Implemented `Get(key string)` returning full `OrgSetting` with `Value` and `Meta`.
  - Implemented `SetWithMeta(key, value string, meta any)` to upsert `key`, `value`, and serialized `meta` JSONB.
  - Implemented `GetAssetMeta(key string)` to safely extract `CloudinaryAssetMeta` from the `meta` column of a given key.
  - Ensured `BulkSet` and `Set` preserve existing `meta` values on conflict.

### 4. Service Updates
- `internal/service/ngo_service.go`:
  - Updated logo & signature replacement / removal to query and store `CloudinaryAssetMeta` directly in `models.OrgKeyLogoURL` and `models.OrgKeySignatureURL` rows via `SetWithMeta`.
