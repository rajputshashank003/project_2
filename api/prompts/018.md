# Prompt 018 — Single-API Global Statistics on Donation & ID Card Lists

**Date:** 2026-08-17  
**Scope:** Backend (`api/`)

---

## User Requests

1. On the donation and ID card admin pages, summary cards should show full database totals (total, pending, approved, total collected), not just the count of items on the current paginated page.
2. Data should come in a single API request so minimal API calls are required.

---

## What Was Done

1. **Donation Global Statistics (`donation_repository.go`, `donation_service.go`, `donation_handler.go`)**:
   - Added `DonationStats` struct and `GetStats()` SQL aggregation query returning `total`, `pending`, `approved`, `rejected`, and `total_collected` (sum of approved amounts).
   - In `DonationHandler.List`, included `stats` alongside `data` and `pagination` in the single JSON response envelope.

2. **ID Card Global Statistics (`id_card_repository.go`, `id_card_service.go`, `id_card_handler.go`)**:
   - Added `IDCardStats` struct and `GetStats()` SQL aggregation query returning `total`, `pending`, `approved`, and `rejected`.
   - In `IDCardHandler.List`, included `stats` alongside `data` and `pagination` in the single JSON response envelope.
