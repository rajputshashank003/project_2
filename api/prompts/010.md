# Prompt 010 — HTTP & Database Request Logging

**Date:** 2026-08-16  
**Scope:** Backend (`api/`)

---

## User Request

> "enable logger in go lang so we can see logs"

---

## What Was Done

1. **HTTP Request Logger Middleware (`internal/middleware/logger.go`)**:
   - Created `RequestLogger()` middleware using Zerolog.
   - Logs every incoming HTTP request with:
     - HTTP Method (`GET`, `POST`, `PATCH`, `DELETE`)
     - Request Path & Query params
     - Response Status code (with colored log levels: Info for 2xx/3xx, Warn for 4xx, Error for 5xx)
     - Request Latency (duration)
     - Client IP address
     - Request ID (`X-Request-ID`)

2. **Registered Middleware in Router (`internal/routes/routes.go`)**:
   - Added `r.Use(middleware.RequestLogger())` to global Gin middleware chain.

3. **GORM Database Query Logging (`internal/database/postgres.go`)**:
   - Configured GORM Logger to `logger.Info` in DevMode (and `logger.Warn` in production) so executed SQL queries and timings are visible.
