# Prompt 017 — Structured OOP CleanupService for 24-Hour Idempotency & OTP Purging

**Date:** 2026-08-17  
**Scope:** Backend (`api/`)

---

## User Requests

1. Implement an OOP structured cleanup service to clean both idempotency keys and OTPs older than 24 hours.

---

## What Was Done

1. **Created `CleanupService` (`api/internal/service/cleanup_service.go`)**:
   - Structured OOP service encapsulating `IdempotencyRepository` and `OTPRepository` dependencies.
   - Configurable execution `interval` (1 hour) and `retentionPeriod` (24 hours).
   - Methods:
     - `Run(ctx context.Context)`: Background ticker with graceful shutdown cancellation.
     - `PerformCleanup()`: Executes purging for both idempotency keys and OTP records older than 24 hours with Zerolog logging.

2. **Added `CleanupOlderThan` in `OTPRepository` (`api/internal/repository/otp_repository.go`)**:
   - Deletes OTP records where `created_at < NOW() - d`.

3. **Integrated into Server (`api/cmd/server/main.go`)**:
   - Replaced inline goroutine with `service.NewCleanupService(idempotencyRepo, otpRepo, 1*time.Hour, 24*time.Hour)` and started `go cleanupSvc.Run(ctx)`.
