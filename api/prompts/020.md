# Prompt 020 — Date Range Query Filtering on Donations and ID Cards

**Date:** 2026-08-17  
**Scope:** Backend (`api/`)

---

## User Requests

1. Support date range queries (`start_date`, `end_date`) on donations and ID cards to allow scalable batched data exports.

---

## What Was Done

1. **Repository Date Range Filtering (`donation_repository.go`, `id_card_repository.go`)**:
   - Updated `ListPaginated` signature to accept `startDate, endDate string`.
   - Supports `YYYY-MM-DD` and RFC3339 formats.
   - `startDate` sets boundary at `00:00:00 UTC` (`requested_at >= ?`).
   - `endDate` sets boundary at `23:59:59.999999999 UTC` (`requested_at <= ?`) ensuring all records on the end date are included.

2. **Service & Handler Integration (`donation_service.go`, `id_card_service.go`, `donation_handler.go`, `id_card_handler.go`)**:
   - Handlers extract `start_date` / `startDate` and `end_date` / `endDate` query parameters from the HTTP request and pass them through to the repository queries.
