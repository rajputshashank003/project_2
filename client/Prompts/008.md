# Prompt 008 — Full-Stack Migration from Base64 File Uploads to FormData

**Date:** 2026-08-16  
**Scope:** Frontend (`client/`)

---

## User Request

> "why we are sending base64 in backend we should send file and formdata fix this in all place in this repo"

---

## What Was Done

### 1. Replaced Network Base64 Overhead with Standard FormData
- Migrated all API request callers to build and submit standard `FormData` payloads containing raw `File` handles.
- Replaced slow browser base64 string encoding with instant zero-RAM `URL.createObjectURL(file)` for instant UI previews.
- In `utils/api_request/utils.ts`, updated `axiosInstance.interceptors.request` to automatically delete `'Content-Type': 'application/json'` when `config.data instanceof FormData`, ensuring the browser attaches `multipart/form-data; boundary=...` and sends the multipart binary stream instead of JSON-serializing the empty FormData object `{}`.

### 2. File Updates in `client/`
1. **Donations**:
   - `types/donation.ts`: `CreateDonationPayload.paymentProof: File`.
   - `utils/api_request/donations.ts`: `createDonation` builds `FormData` with `paymentProof` file.
   - `screens/Donate/useDonate.ts`: Retains `File` object and submits directly.
2. **ID Cards**:
   - `types/id_card.ts`: `CreateIdCardPayload.passportPhoto: File` & `paymentProof: File`.
   - `utils/api_request/id_cards.ts`: `createIdCardRequest` builds `FormData` with `passportPhoto` and `paymentScreenshot`.
   - `screens/IDGenerate/useIDGenerate.ts`: Passes `File` handles with instant `URL.createObjectURL` preview.
3. **Gallery**:
   - `utils/api_request/gallery.ts`: `uploadGalleryImage` sends `FormData` with `image: File` and optional `caption`.
   - `screens/AdminGallery/useAdminGallery.ts`: Direct file upload.
4. **Noticeboard**:
   - `types/notice.ts`: `CreateNoticePayload.image?: File`.
   - `utils/api_request/notices.ts`: `createNotice` sends `FormData` with `image: File`.
   - `screens/AdminNoticeboard/useAdminNoticeboard.ts`: Uses `URL.createObjectURL` and submits `File`.
5. **Team Members**:
   - `types/team_member.ts`: `UpdateTeamMemberPayload.photo?: File`.
   - `utils/api_request/team_members.ts`: `updateTeamMember` sends `FormData` with `photo: File`.
   - `screens/AdminTeam/useAdminTeam.ts`: Manages `photoFile?: File` and `photoPreview: string`.
6. **Events**:
   - `types/event.ts`: Defined `EventImageItem` (`new` with `File` vs `existing` with `url`).
   - `utils/api_request/events.ts`: `createEvent` and `updateEvent` append files to `images` and URLs to `existingUrls`.
   - `screens/AdminEvents/useAdminEvents.ts`: Manages `pendingImages` with `file: File` and `previewUrl: string`.
7. **Org Settings & Digital Signature**:
   - `utils/api_request/ngo.ts`: `uploadLogo(file: File)` and `uploadSignature(file: File)` send `FormData` with `logo` / `signature` files; `deleteLogo` and `deleteSignature` send deletion flags.
   - `screens/AdminSettings/useAdminSettings.ts` & `screens/AdminRequestIdCard/useAdminRequestIdCard.ts`: Directly invoke `uploadLogo(file)` and `uploadSignature(file)`.
8. **Menu Dropdown (Admin Control)**:
   - Refactored `components/MenuDropdown/index.tsx` to use clean relative container positioning and a click-outside listener instead of a global blurred overlay backdrop (`backdrop-blur-xs bg-slate-900/30`), ensuring the Admin button and Navbar remain 100% sharp, un-blurred, and interactive when the dropdown is open.
9. **Mobile Navigation Drawer & Modals Portal Escape**:
   - Refactored the Mobile Navigation Drawer in `components/Navbar/index.tsx` to mount through `createPortal(..., document.body)`. Previously, being nested inside `<header className="sticky top-0 z-40 bg-white/95 backdrop-blur-md">` caused browsers to treat `<header>` as the CSS containing block for `fixed` children, causing the drawer to collapse to header height and overlap transparently over page content.
   - Mounted `components/Modal/index.tsx` through `createPortal(..., document.body)` so all dialogs (logout confirmation, edit modals, onboarding) render with pristine full-screen backdrops and solid surfaces.
10. **Public Gallery Screen (`/gallery`)**:
   - Created public `screens/Gallery/Gallery.tsx`, `useGallery.ts`, and `GalleryComponents.tsx` to view the full NGO photo archive with a responsive grid, hover zoom effects, and full-resolution lightbox modal.
   - Registered `/gallery` route in `App.tsx`, added `Gallery` link with `ImageIcon` to `Navbar/index.tsx` `NAV_LINKS`, and added `Photo Gallery` link to `Footer/index.tsx`.
11. **Navbar & Drawer Logo Skeleton & Fill Aspect**:
   - Implemented animated pulse skeleton placeholder for NGO Logo and Name in `components/Navbar/index.tsx` and `components/Footer/index.tsx` while `isConfigLoading` is active, preventing flash of default placeholder text.
   - Updated `LogoBadge` image styling from `object-contain` to `w-full h-full object-cover` within an `overflow-hidden` rounded container, so uploaded logos fill the container badge cleanly.
12. **Navbar Responsive Breakpoint at 1200px**:
   - Updated desktop navigation and mobile burger triggers in `components/Navbar/index.tsx` to switch at `1200px` (`min-[1200px]:`), ensuring the mobile drawer menu is displayed for all screen widths under 1200px.
