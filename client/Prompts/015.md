# Prompt 015 — Email Auto-Fill for ID Card & Donation Forms + Profile Designation Badge Fix

**Date:** 2026-08-16  
**Scope:** Frontend (`client/`)

---

## User Requests

1. Auto-fill the email field from the user profile when generating an ID Card or creating a Donation/Certificate, while allowing the user to change/edit it.
2. Fix user profile designation badge showing `Admin` instead of actual organization designation (`Secretary`).

---

## What Was Done

1. **Email Auto-Fill (`useIDGenerate.ts` & `useDonate.ts`)**:
   - Initialized `email: user?.email || ""` in form initial state.
   - Added `useEffect` in both hooks to populate `email`, `name`, and `phone` from `user` if fields are empty upon async auth load.
   - Users are free to modify or customize the email in the input field before submitting.

2. **Profile Designation Badge Display (`UserProfile.tsx`)**:
   - Replaced ternary suppression with direct designation display (`user?.designation || "Member"`), correctly displaying "Secretary" (or "President", "Volunteer", "Member").
   - Added an accompanying `Admin` badge when `user?.role === "admin" && user?.designation !== "admin"`.

---

## Verification

- `npm run build` in `client/` compiled cleanly with 0 errors.
