# Prompt 012 — Profile Mobile Layout Fix, Modal Closure & Request Timeout Increase

**Date:** 2026-08-16  
**Scope:** Frontend (`client/`)

---

## User Requests

1. Fix Profile page mobile UI layout where donation cards and ID cards text, dates, status badges, and buttons were overlapping and squished.
2. Fix profile onboarding modal ("Continue to Portal") not closing on submit.
3. Fix organization config update API timeout when uploading logo.

---

## What Was Done

1. **Profile Mobile Layout Redesign**:
   - `DonationList.tsx`: Restructured `DonationRow` into a responsive stacked card (`flex flex-col sm:flex-row`). Separated amount, status badges, dates, certificate numbers, and the "View Certificate" button so they never collide or overlap on small viewports.
   - `IdCardList.tsx`: Restructured `IdCardRow` into a responsive card layout with dedicated space for designation, status badge, application dates, card numbers, validity, and "View ID Card" button.
   - `UserProfile.tsx`: Replaced the long wrapping underline tab bar with a responsive 2-column segmented pill control on mobile (`grid grid-cols-2`) with concise labels (`Donations` & `ID Cards`) and count badges. Fixed profile header text wrapping.

2. **Profile Completion Modal (`ProfileCompletionModal/index.tsx`)**:
   - Enhanced `updateUser` with fallbacks for `name`, `email`, and `bloodGroup` to ensure `AuthContext.user` is immediately populated with complete fields upon successful submission, causing `isProfileComplete` to evaluate to `true` and cleanly unmounting the modal.

3. **HTTP Request Timeout Increase (`utils/api_request/utils.ts`)**:
   - Increased the default Axios timeout from 15s (`15000ms`) to 60s (`60000ms`) to accommodate large high-resolution image uploads over cellular/slower networks without timing out.

## Verification

- `npm run build` compiled cleanly with 0 errors.
