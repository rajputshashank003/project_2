# Prompt 006 — User Profile Screen & Login WhatsApp Copy Changes

**Date:** 2026-08-15  
**Scope:** Frontend (`client/`)

---

## User Request

1. Update Login UI copy to clarify that OTP is sent to WhatsApp instead of SMS.
2. Remove any demo hints from login inputs.
3. Build a dedicated User Profile page (`/profile`) where authenticated users can view all their submitted donations (with direct certificate download links upon approval) and ID card requests.

---

## What Was Done

### 1. Login Copy Updates
- `screens/Login/components/LoginSteps.tsx`:
  - Updated disclaimer: "OTP will be sent to your WhatsApp number."
  - Updated verification header: "We've sent a 6-digit OTP on WhatsApp to +91 {phone}"
  - Removed demo hint `(For demo, enter any 6 digits)`.
- `screens/Login/useLogin.ts`:
  - Updated toast: `OTP sent on WhatsApp to +91 ${cleaned}`.

### 2. API Layer
- `utils/api_request/my.ts`:
  - Created `getMyDonations(page, limit)` -> calls `GET /api/v1/my/donations`.
  - Created `getMyIdCards(page, limit)` -> calls `GET /api/v1/my/id-cards`.

### 3. User Profile Screen (`screens/UserProfile/`)
- `UserProfile.tsx`: Top user badge and tabs for "My Donations & Certificates" and "My ID Cards".
- `useUserProfile.ts`: Hook for managing tab switching and paginated data fetching for both endpoints.
- `context.ts`: React context for the profile state.
- `components/DonationList.tsx`: Donation list rows showing amount, date, status badges, certificate number, and "View Certificate" links.
- `components/IdCardList.tsx`: ID card list rows showing designation, request date, expiry date, status badges, and "View ID Card" links.

### 4. Navigation & Routing
- `App.tsx`: Registered lazy-loaded `/profile` protected route.
- `components/Navbar/index.tsx`:
  - Desktop: User badge links to `/profile` with hover state.
  - Mobile: Added "My Profile" nav link for authenticated users.
