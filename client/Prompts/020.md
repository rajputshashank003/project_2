# Prompt 020 — Organization-Wide Global Stats on Donation & ID Card Admin Pages

**Date:** 2026-08-17  
**Scope:** Frontend (`client/`)

---

## User Requests

1. On donation and ID card admin pages, summary cards should show full database totals (total, pending, approved, total collected), not just the count of items on the current paginated page.
2. Data should come in a single API request so minimal API calls are required.

---

## What Was Done

1. **API Envelope Extension (`utils.ts`, `donations.ts`, `id_cards.ts`)**:
   - Extended `PaginatedResponse<T, S = unknown>` with optional `stats?: S`.
   - Defined `DonationStats` and `IdCardStats` types.

2. **Donation Requests Screen (`useAdminRequestDonation.ts`, `AdminRequestDonation.tsx`)**:
   - `useAdminRequestDonation` captures `stats` directly from the single `getDonations` response without extra network requests.
   - `AdminRequestDonation` renders global metrics in the top 4 summary cards: `stats.total`, `stats.pending`, `stats.approved`, and `formatCurrency(stats.totalCollected)`.

3. **ID Card Requests Screen (`useAdminRequestIdCard.ts`, `AdminRequestIdCard.tsx`)**:
   - `useAdminRequestIdCard` captures `stats` directly from the single `getIdCardRequests` response.
   - `AdminRequestIdCard` renders global metrics in the top 3 summary cards: `stats.total`, `stats.pending`, and `stats.approved`.
