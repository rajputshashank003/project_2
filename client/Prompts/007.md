# Prompt 007 — Mandatory Profile Onboarding, Mobile Menu Redesign, Mission/Vision Settings & Fixes

**Date:** 2026-08-15  
**Scope:** Frontend (`client/`)

---

## User Request

1. Mandatory user onboarding modal: users cannot use the portal without completing their Name and Email (forces both new signups and existing users with missing fields).
2. Deep link redirect after login (redirects user back to intended page upon authenticating).
3. Redesign Navbar: interactive desktop profile card and a brand new modern mobile navigation drawer.
4. Remove Secretary signature and name from Certificate canvas right side.
5. Add Mission & Vision editing in Admin Settings and display in About page.
6. Fix Admin Team slot clear/add/remove crash and state synchronization.
7. Fix logo upload and founded year validation in Admin Settings.
8. Add smooth skeleton loaders to Home page gallery section.

---

## What Was Done

### 1. Mandatory Profile Onboarding
- `components/ProfileCompletionModal/index.tsx`:
  - Created blocking modal that triggers whenever `isAuthenticated && !isProfileComplete`.
  - Captures Full Name and Email with instant client-side validation.
  - Calls `updateMyProfile()` (`PATCH /api/v1/my/profile`) and updates `AuthContext` state on success.
- `context/AuthContext.tsx`:
  - Added `isProfileComplete: boolean` check (`name.trim() && email.trim()`).
  - Added `updateUser(fields: Partial<AuthUser>)` method to sync in-memory user and localStorage.
- `App.tsx`:
  - Included `<ProfileCompletionModal />` at root level.
  - Updated `ProtectedRoute` to pass `location` in state for redirect after login.
- `screens/Login/useLogin.ts`:
  - Added redirection logic that checks `?redirect=...` query parameter and `location.state.from`.

### 2. Navbar & Mobile Menu Redesign
- `components/Navbar/index.tsx`:
  - Desktop: Replaced simple text pill with an interactive user card showing avatar initial, name/phone, and "View Profile →" link with hover states.
  - Mobile: Built a modern slide-out drawer with blurred backdrop, user card summary with role badge, rich icon navigation, admin management section, and logout action.

### 3. Certificate & Digital Signature
- `components/CertificateCanvas/index.tsx`:
  - Removed secretary section from the right side.
  - Formatted left side with President signature and title.
- `screens/IDCardView/useIDCardView.ts` & `screens/CertificateView/useCertificateView.ts`:
  - Freshly fetched `getNgoConfig()` in parallel to ensure the latest digital signature and logo are always displayed.

### 4. Admin Settings, Mission & Vision
- `types/ngo.ts`: Added `mission?: string` and `vision?: string` to `NgoConfig`.
- `context/AppContext.tsx`: Added `mission` and `vision` default values.
- `utils/api_request/ngo.ts`:
  - Added `mission` and `vision` to `UpdateNgoConfigPayload`.
  - Fixed logo/signature upload: only sends `logoBase64` / `signatureBase64` when new base64 data URIs (`data:...`) are uploaded.
- `screens/AdminSettings/components/AdminSettingsComponents.tsx`:
  - Added `MissionVisionSettingsForm` with textareas for Mission and Vision.
  - Fixed founded year input to prevent garbage numbers (`min={1900}`, `max={2100}`, max 4 characters).
- `screens/AdminSettings/AdminSettings.tsx`:
  - Included `MissionVisionSettingsForm` in the settings page.
- `screens/About/About.tsx`:
  - Replaced hardcoded mission and vision strings with `ngoConfig.mission` and `ngoConfig.vision` (with fallback text).

### 5. Navbar Org Logo & Logo Management
- `components/Navbar/index.tsx`:
  - Created `LogoBadge` component that displays `ngoConfig.logoUrl` if available and seamlessly falls back to the green rounded leaf badge if not set or on image load error.
  - Used `LogoBadge` in both desktop header and mobile drawer header.
- `utils/api_request/ngo.ts`:
  - Added `uploadLogo(logoBase64)` and `deleteLogo()` helper functions.
- `screens/AdminSettings/useAdminSettings.ts`:
  - Added instant logo upload (`uploadLogo`) and logo deletion (`deleteLogo`) handlers with immediate global state update.
- `screens/AdminSettings/components/AdminSettingsComponents.tsx`:
  - Added "Change" and "Delete" (trash icon) action buttons for the organization logo.

### 6. Admin Team & Events Fixes
- `screens/AdminTeam/useAdminTeam.ts`:
  - Updated `handleAddSlot`, `handleRemoveSlot`, and `confirmClear` to consume the updated array / model returned by the backend.
- `screens/Home/components/HomeComponents.tsx`:
  - Added skeleton loaders and image `onLoad` transitions to the gallery section.
