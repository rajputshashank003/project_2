# Prompt 013 — ID Card Validity Fix & Responsive Aspect-Ratio Scaling for Certificate and ID Card

**Date:** 2026-08-16  
**Scope:** Frontend (`client/`)

---

## User Requests

1. Fix `/certificate/:id` page on mobile where the certificate preview was cropped horizontally and overflowing instead of scaling down to fit the screen while maintaining its exact landscape aspect ratio.
2. Fix ID card preview on mobile viewports and inside admin preview modals where the card was overflowing the modal/screen horizontally.
3. Fix ID card validity display showing `Valid till: Lifetime` even when the admin approved the ID card with a specific validity (e.g., 1 Year, 2 Years).

---

## What Was Done

1. **ID Card Validity Display Fix (`useIDCardView.ts` & `IdCardRequestComponents.tsx`)**:
   - Passed `expiryDate: data.expiryDate` into `cardData` in `useIDCardView.ts` and `expiryDate: previewItem.expiryDate` in `IdCardRequestComponents.tsx` (`IDCardPreviewModal`).
   - `IDCardCanvas` now correctly displays `Valid till: <Formatted Date>` (e.g. `Valid till: 16 Aug 2027` for 1 year) and displays `Valid till: Lifetime` only when 0 years validity is selected.

2. **Responsive Aspect-Ratio Certificate Scaling (`CertificateCanvas/index.tsx` & `CertificateView.tsx`)**:
   - Implemented dynamic scale calculation (`scale = Math.min(1, containerWidth / 794)`) using `ResizeObserver`.
   - Set outer container dimensions to `width: 794 * scale` and `height: 562 * scale` with `transform: scale(scale)` centered in parent.
   - Preserved exact A4 landscape aspect ratio (794:562, ~1.4128) across all mobile devices (360px–414px) and tablets without horizontal scrollbars or clipping.
   - Updated `downloadPng` and `downloadPdf` to explicitly export unscaled `794px x 562px` at `pixelRatio: 2.5` for full ultra-high resolution (`1985x1405px`) downloads.
   - Optimized container padding in `CertificateView.tsx` (`p-3 sm:p-6 flex justify-center`).

3. **Responsive Aspect-Ratio ID Card Scaling (`IDCardCanvas/index.tsx` & `IDCardView.tsx`)**:
   - Added `ResizeObserver` to dynamically compute `scale = Math.min(1, containerWidth / baseWidth)` (where `baseWidth` is 320px when stacked on mobile or 656px side-by-side on desktop).
   - Wrapped cards in dynamic scaled container (`width: baseWidth * scale`, `height: baseHeight * scale`) with `transform: scale(scale)`.
   - Cards fit seamlessly inside narrow mobile viewports and admin preview modals without horizontal scrolling or edge cutoff.
   - Updated `downloadPng` and `downloadPdf` with unscaled `320px x 200px` dimensions at `pixelRatio: 2.5` for high-resolution exports.
   - Optimized padding in `IDCardView.tsx` (`p-3 sm:p-6 flex justify-center`).
