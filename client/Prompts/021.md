1. **Unified Approved Contributions Excel Export (`excel_exporter.ts`, `useAdminRequestDonation.ts`, `DonationRequestComponents.tsx`)**:

   - Merged both approved donations and approved ID card applications into a single `.xlsx` report.
   - Added `Type` column with values `"Donation"` and `"ID Card"`.
   - Included numeric amount for donations to support Excel auto-sum, and appended a grand total summary row at the bottom.
   - `handleExportExcel` fetches all approved records across database pages (up to 1,000).
   - Added `isExportingExcel` state in `useAdminRequestDonation.ts` and dynamic spinner + `"Exporting…"` label with disabled state on the export button.

2. **Certificate Canvas Visual Clearance (`CertificateCanvas/index.tsx`)**:
   - Increased inner container padding to `padding: "16px 58px 48px"`.
   - The Authorized Signatory block and Certificate Number now sit with generous clearance above the green corner brackets and frame.

3. **Developer Portfolio Attribution in Footer (`Footer/index.tsx`)**:
   - Added *"Designed & Developed by [Shashank Rajput](https://rajputshashank.vercel.app)"* in the footer bottom bar with an external link icon opening in a new tab.
