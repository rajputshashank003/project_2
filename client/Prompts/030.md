# Prompt 030 — Footer Logo, ID Card Fee Note Modal & Lifetime Option Removal

**Date:** 2026-08-18  
**Scope:** Frontend (`client/`)

---

## User Requests

1. In footer, logo was not showing (it was hardcoded to a static leaf icon).
2. Add a Note button on ID card generation page (`/id-generate`) where clicking it opens a modal showing:
   - ₹500 for 1 Year ID Card
   - ₹1,000 for 2 Years ID Card
   - ₹2,000 for 3 Years ID Card
   - Close button
3. Remove Lifetime option from ID card approval.

---

## What Was Done

1. **Footer Logo (`client/src/components/Footer/index.tsx`)**:
   - Updated Footer Brand component to render `ngoConfig.logoUrl` in a rounded container with `onError` handling.
   - Falls back gracefully to the emerald `Leaf` icon if `logoUrl` is absent or fails to load.
   - Shows pulse skeleton loader while `isConfigLoading` is true.

2. **ID Card Fee Note Modal & Buttons (`client/src/screens/IDGenerate/`)**:
   - `useIDGenerate.ts`: Added `isNoteModalOpen` state and `setIsNoteModalOpen`.
   - `components/IDGenerateComponents.tsx`:
     - Added "Fee Details & Note" button in `IDPaymentDetails` header.
     - Added "View Fee Structure" button in `IDPaymentDetails` bottom note.
     - Added "Fee Structure Note" button beside the amount input label in `IDForm`.
     - Created `IDCardNoteModal` with structured tier cards (₹500 for 1 yr, ₹1,000 for 2 yrs, ₹2,000 for 3 yrs) and full close button.
   - `IDGenerate.tsx`:
     - Rendered `<IDCardNoteModal />`.

3. **Lifetime Option Removal (`client/src/screens/AdminRequestIdCard/`)**:
   - `components/IdCardRequestComponents.tsx`: Removed `{ label: "Lifetime", value: 0 }` from `ActionModal`.
   - `useAdminRequestIdCard.ts`: Changed default state and reset handlers from `0` to `1` (1 Year).
