# Prompt 023 — ID Card Contribution Amount, Admin Review & Excel Integration

**Date:** 2026-08-17  
**Scope:** Frontend (`client/`)

---

## User Requests

1. Add required contribution / donation amount option in ID Card request form.
2. Populate the ID Card amount in exported Excel sheets and total sums.
3. Show amount in Admin ID Card review table and preview modal.

---

## What Was Done

1. **ID Card Form & Validation (`IDGenerate`, `useIDGenerate.ts`, `IDGenerateComponents.tsx`)**:
   - Added `amount` field in `IdCardFormData`.
   - Added validation enforcing positive numerical input (`min ₹1`).
   - Rendered **`Donation / Card Fee Amount (₹) *`** input field with `₹` symbol prefix in the form.
   - Forwarded `amount` in `CreateIdCardPayload` and multipart `FormData`.

2. **Unified Excel Export (`excel_exporter.ts`)**:
   - For approved ID cards with `c.amount > 0`, exported `c.amount` into the `"Amount (₹)"` column.
   - Accumulated `c.amount` into `totalAmount` for the bottom summary row.

3. **Admin ID Card Panel (`AdminRequestIdCard`)**:
   - Added **Amount** column to `IdCardRequestTable`.
   - Added applicant and declared amount summary pill in `IDCardPreviewModal` before the payment screenshot.

4. **Currency Icon Overlay Fix**:
   - Added `.form-input.pl-8` rule in `index.css`.
   - Updated input to `pl-10` with `left-3.5` `₹` icon to ensure clean spacing without any overlay onto input numbers.
