# Prompt 014 — Certificate Signature Layout Fix, Single-Line Mobile Tabs & User Role DB Synchronization

**Date:** 2026-08-16  
**Scope:** Frontend (`client/`) & Backend (`api/`)

---

## User Requests

1. Fix Certificate signature layout and bottom border overflow when both logo and purpose are present on `/certificate/:id`.
2. Keep modal tab titles ("Payment Screenshot" and "Certificate Preview") on a single line on mobile screens.
3. Synchronize user profile, role (`Admin` / `User`), and designation directly from the database instead of relying on stale `localStorage`.

---

## What Was Done

1. **Certificate Signature & Layout Fix (`CertificateCanvas/index.tsx`)**:
   - Restructured `#certificate-print-area` using a proportional `flex flex-col justify-between` layout within the fixed `794px` x `562px` canvas (`padding: 22px 48px 18px`).
   - Balanced typography and spacing (logo `40px`, title `19px`, donor name `23px`, details `12.5px`, signature `32px`).
   - The President signature block, President title, and Certificate Number are guaranteed to sit `~25px` above the bottom green border with zero overflow or clipping under all conditions (with or without logo, with or without purpose).
   - High-resolution unscaled PNG and PDF downloads (`pixelRatio: 2.5`) remain fully preserved.

2. **Admin Donation Modal Tab Formatting & Data Matching (`DonationRequestComponents.tsx`)**:
   - Passed `ngoLogo: ngoConfig.logoUrl` and `purpose: "General NGO Activities"` to `certificateData` so the admin modal preview matches the public certificate view 1:1.
   - Updated tab button styling to `px-2.5 sm:px-4 py-2 text-xs sm:text-sm font-semibold whitespace-nowrap gap-1.5 sm:gap-2 flex-1 sm:flex-initial justify-center` so tab titles stay cleanly on one line on mobile phones without wrapping.

3. **User Profile & Admin Role DB Synchronization (`api/` & `client/`)**:
   - **Backend**: Implemented `GetMyProfile` in `user_service.go` and `user_handler.go`, registered `my.GET("/profile", userH.GetMyProfile)` in `routes.go`.
   - **Frontend**: Added `getMyProfile()` in `auth.ts` and `refreshUser()` in `AuthContext.tsx`. Automatically refreshes user profile from DB on app load and on `/profile` screen mount, keeping `Admin` / designation badges always live and synchronized.
