# Prompt 025 — Cross-Browser Clipboard Copy Fix on Donation Page

**Date:** 2026-08-17  
**Scope:** Frontend (`client/`)

---

## User Requests

1. Fix UPI ID copy button not copying on the donation page.

---

## What Was Done

1. **`copyToClipboard` Utility (`helpers.ts`)**:
   - Created a robust cross-browser clipboard copying utility.
   - Tries `navigator.clipboard.writeText` and transparently falls back to `document.execCommand('copy')` on non-HTTPS origins, restricted iframe contexts, or older browsers.

2. **Donation Page Copy Handlers (`useDonate.ts`)**:
   - Updated `handleCopyUpi`, `handleCopyPhone`, `handleCopyAccount`, and `handleCopyIfsc` to use `copyToClipboard`.
   - Guaranteed fallback value `ngoConfig.upiId || "ngo@upi"` so empty values are never passed.
   - Added success and error feedback toasts.
