## Context

N_P (NGO Platform) needed a way to send WhatsApp messages for OTP delivery, donation approvals,
and ID card approvals. Twilio WhatsApp was an option but requires DLT registration + paid account
for Indian SMS. The free WhatsApp sandbox only allows pre-approved templates.

An unofficial approach using `whatsmeow` (Go library that implements WhatsApp Web multi-device
protocol) allows free, unlimited WhatsApp messages without Meta approval or Twilio billing.
Since `whatsmeow` is a heavy dependency, it was isolated into a standalone microservice.

---

## What Was Built

A standalone Go HTTP microservice that:
1. Connects to WhatsApp via the `whatsmeow` library using a linked device session
2. Persists the session in SQLite (`store/whatsapp.db`)
3. Exposes `POST /send`, `GET /status`, `GET /qr` endpoints
4. Is called by N_P's `WhatsAppLocalService` via HTTP

## Integration in N_P

Three new files in N_P:
- `service/messenger.go` — `Messenger` interface
- `service/whatsapp_local_service.go` — HTTP caller to this service
- `service/multi_messenger.go` — routes based on `MESSAGING_TYPE` env

N_P env: `MESSAGING_TYPE=whatsapp_local`, `WHATSAPP_LOCAL_URL=http://localhost:8080`

---

## How to Start Using

1. `go mod tidy` (downloads whatsmeow and deps)
2. `go run cmd/main.go`
3. Open `http://localhost:8080/qr` in browser
4. Scan QR from WhatsApp → Linked Devices → Link a Device
5. Service sends WhatsApp messages to any number, free

## Notes for Future Agent

- whatsmeow import path: `go.mau.fi/whatsmeow`
- Session container import: `go.mau.fi/whatsmeow/store/sqlstore`
- JID format for Indian numbers: `+91XXXXXXXXXX@s.whatsapp.net` (use `types.NewJID`)
- `waE2E.Message.Conversation` is a proto.String for plain text messages
- CGO must be enabled to compile `go-sqlite3` — use `CGO_ENABLED=1` in Docker
- QR code PNG generation requires an extra library (e.g. `github.com/skip2/go-qrcode`)
